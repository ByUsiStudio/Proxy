配置导出 / 导入 / 分享

用于迁移或分享隧道配置
勾选后导出的 JSON 与二维码会带上账号密码，等同于把密码本身交出去，请勿公开分享、张贴或上传到任何公共渠道。

默认不含凭据，导出的配置只能用于本机已经登录的账号环境；仅在自己信任的设备之间迁移时才勾选。

尚未导出
分享文本使用紧凑格式，以便装入二维码。
导入需要账号密码：配置里缺少 username / password 时，控制台会先弹窗向你索取当前账号密码（与「重新验证密码」相同），再把缺失的凭据补全进待导入的隧道后一次性提交。
补全只在内存中完成，密码仅保存在当前标签页的会话存储里，不会写入磁盘。
