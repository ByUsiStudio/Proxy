首页 / KSWEB 穿透教程

用 KSWEB + Proxy 客户端发布手机上的网站

整理：情恋海 QQ：1772712580 适用：安卓手机 + KSWEB

准备工具

  • 一台安卓手机（建议 Android 10 以下的系统，兼容性更好）
  • 同一局域网内的一台路由器（手机需要能正常上网）
  • 软件：KSWEB（安卓上的 Web 服务器）与 Proxy 客户端

操作步骤

  1. 安装并打开 KSWEB，启动主机 Lighttpd。
  2. 点击主机条目 localhost (8080 /mnt/sdcard/htdocs) 进入编辑，使用默认路径确认保存。
  3. 用文件管理器（推荐 MT 管理器）打开 /sdcard/htdocs/，删除自带的 index.php， 新建 index.html，内容见下方代码块。 注意文件名必须是 index.html，且放在 htdocs 根目录。
  4. 打开 Proxy 客户端，完成注册与登录。
  5. 在「添加穿透」中填写内网 IP（手机在局域网中的地址，或直接填 127.0.0.1） 与内网端口 8080，选择穿透服务器、域名与外网端口，保存。
  6. 复制生成的域名地址（形如 http://你的域名/）在浏览器中打开， 能看到下面的测试内容就说明穿透成功了。

index.html 内容

复制下面的内容保存为 index.html：

<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>测试网页</title>
</head>
<body>
  <h1>在自己的网页上看到这段话，说明你已经成功了</h1>
</body>
</html>

若浏览器不允许自动复制，请手动长按全选后复制。

常见问题

打不开穿透后的地址

  • 确认 KSWEB 中的 Lighttpd 主机处于运行状态，并且本机访问 http://127.0.0.1:8080/ 正常。
  • 确认客户端控制台的隧道状态为「运行中」，域名没有被其他隧道占用。
  • 部分手机在息屏后会限制后台网络，建议关闭电池优化或将客户端加入白名单。

自定义域名怎么配置

  • 在控制台的「域名管理」中添加自定义域名。
  • 到你的 DNS 服务商处，把该域名 CNAME 解析到分配给你的二级域名。
  • 解析生效后再创建隧道并选择该自定义域名。
