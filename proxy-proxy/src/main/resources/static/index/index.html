功能特性

从个人调试到生产内网服务发布，一套客户端覆盖主流平台。

数据转发，稳定可靠

只要能上网就能穿透，不依赖 NAT 类型，极端网络环境下依然保持连接与自动重连。

免费二级域名

注册即可获得二级域名，直接对外发布网站与应用，无需备案域名也能快速联调。

自定义域名与证书

绑定自己的域名，并可加载自有 SSL 证书，端到端加密，客户端与服务端都支持。

固定端口映射

随机分配或指定外网端口，数据库、SSH、游戏服务等非 HTTP 场景同样适用。

多平台客户端

提供 Java 与 Golang 两套实现，覆盖 Windows、Linux、Termux、安卓、OpenWrt、NAS 与 Docker。

自动穿透配置

把穿透配置保存到云端，客户端携带设备 ID 启动即自动创建隧道，设备重启免重复配置。

快速开始

Termux 与 Linux 一条命令完成部署，其余平台下载对应客户端即可。

一键安装客户端

在 Termux 或 Linux 终端中执行下面的命令：

bash -c "$(curl -sSL https://gitee.com/byusi/proxy/raw/master/shell/install2.sh)"
bash -c "$(curl -sSL https://raw.githubusercontent.com/ByUsiTeam/Proxy/master/shell/install2.sh)"

卸载：bash -c "$(curl -sSL https://gitee.com/byusi/proxy/raw/master/shell/uninstall.sh)"

启动客户端

直接运行即可，本地控制台默认地址为 http://127.0.0.1:10240/：

proxy-client

如需随设备自动创建隧道，带上云端设备 ID 启动：

proxy-client -deviceId=你的设备ID

在控制台添加穿透

打开本地控制台登录后，点击「添加穿透」，填写内网 IP 与端口，选择穿透服务器、域名与外网端口， 保存即可通过生成的地址访问内网服务。支持批量停止、实时日志、流量统计与配置导出分享。
